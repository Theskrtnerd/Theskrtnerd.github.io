# Developer setup post icon sources

The figures in `content/posts/my-setup-for-the-ai-era.md` use the actual macOS app icons, converted from ICNS to 256px PNGs for local serving. App names remain visible beside each icon and the images have descriptive alt text. The figures use live HTML text, so their labels resize and reflow on narrow screens.

| Asset | Source package | Product |
| --- | --- | --- |
| `t3-code.png` | T3 Code Alpha, `icon.icns` | https://github.com/pingdotgg/t3code |
| `aside.png` | Aside, `app.icns` | https://aside.com/ |
| `spokenly.png` | Spokenly, `AppIcon.icns` | https://spokenly.app/ |
| `zed.png` | Zed, `Zed.icns` | https://zed.dev/ |
| `still.png` | Still build, `Still.icns`, generated by its `scripts/make-icon.swift` | https://github.com/viciousbuilders/still |
| `apple-notes.png` | macOS Notes, `AppIcon.icns` | https://support.apple.com/guide/notes/welcome/mac |

Assets live in `public/images/posts/my-setup-for-the-ai-era/`. The figures group tools by the roles described in the post; they do not depict a software integration or a benchmark.
